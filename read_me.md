# Analisi NLP - The Jungle Book

This project has been created for the exam of the course "Python for linguistics". The main scope of this code is to analyse the texts: "The Jungle book" by R. Kipling and "The book of dragons" by E. Nesbit by levaraging different coding techniques and available libraries for NLP in Python.

---

## Libraries used 

* **NLTK** (Concordances and tokenization)
* **Stanza** (Pipeline NLP, POS Tagging, Lemmatizzazione)
* **Requests** (Downloading the text)
